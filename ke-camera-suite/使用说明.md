# 摄像头服务套件

一套自包含的摄像头接入服务包：**实时播放 + 云台控制 + 录像下载**。
无需安装任何前置依赖，解压后一个 BAT 装完。

> **整个文件夹可以放在任意路径、复制到任意机器。** 所有脚本都用「脚本自身所在目录」
> 作为根路径，不写死任何绝对路径。换位置后重跑 `install-service.bat` 即可，
> 服务注册和环境变量会自动指向新位置。
>
> 需要部署到 Linux？见 `Linux部署指南.md`，或直接用 `linux/install.sh`。

---

## 一、包含什么

| 序号 | 服务 | 端口 | 作用 |
|:---:|---|:---:|---|
| 1 | `KE-WebRTCStreamer` | 8000 | 把摄像头 RTSP 转成 WebRTC，浏览器实时播放 |
| 2 | `KE-OnvifPtzService` | 3000 | ONVIF 云台控制（方向/缩放/预置位）+ 获取 RTSP 地址 |
| 3 | `KE-RecordService` | 3001 | 历史录像下载，按时间段导出 mp4 |

外加 **ffmpeg**（`tools\ffmpeg.exe`）—— 它不是服务，只在录像下载时被调用，用完即退。

## 三、快速开始（3 步）

### 第 ① 步：安装服务

右键 `install-service.bat` → **以管理员身份运行**

脚本会自动完成：
1. 检查文件完整性
2. 注册 `FFMPEG_PATH` 系统环境变量
3. 注册三个 Windows 服务（开机自启、异常自动重启）
4. 启动三个服务

看到三个服务都是 `RUNNING` 就成功了。

### 第 ② 步：放行防火墙

右键 `firewall-rules.bat` → **以管理员身份运行**

### 第 ③ 步：验证

| 地址 | 期望结果 |
|---|---|
| `http://localhost:8000` | webrtc-streamer 播放器页面 |
| `http://localhost:3000/health` | `{"success":true,...}` |
| `http://localhost:3001` | 录像下载服务信息页 |
| `http://localhost:3001/health` | `"ffmpegAvailable": true` |

### 第 ④ 步：打开调试页面（推荐）

双击 `start-web.bat` —— 自动启动本地网页服务并打开浏览器。一个页面里就能把三个功能全测完：

| 区域 | 能做什么 |
|---|---|
| 顶部服务栏 | 改服务地址和端口，实时检测三个服务是否可用（绿点/红点） |
| 左侧播放器 | WebRTC 实时预览 / 录像回放，自动生成 RTSP 地址，也可手动粘贴 |
| 右侧控制面板 | 播放模式切换、码流切换、回放时间段、云台方向键（按住持续移动）、变倍、速度调节 |
| 设备参数 | 品牌（海康/大华/宇视）、通道、IP、各端口、账号密码 —— 全部手填 |
| 录像下载 | 选时间段 → 查录像 → 下载 → 进度条 → 一键保存 mp4 |
| 运行日志 | 所有操作的实时日志，按级别着色 |

**特点**：单文件页面、**不依赖外网**（无任何 CDN 资源）、零第三方库，关掉黑窗口即停止。

设备参数会存进浏览器 localStorage（**密码不存**），下次打开自动回填。

## 四、服务① 实时播放（webrtc-streamer）

浏览器直接播放摄像头画面，延迟 **500ms 以内**。

前端调用方式：

```html
<video id="v" autoplay muted playsinline></video>
<script src="http://localhost:8000/webrtcstreamer.js"></script>
<script>
  const webRtcServer = new WebRtcStreamer('v', 'http://localhost:8000');
  webRtcServer.connect('rtsp://admin:密码@192.168.1.100:554/stream1');
  // 断开：webRtcServer.disconnect()
</script>
```

RTSP 地址可以从服务② 的 `/getRtsp` 接口动态获取，也可以前端直接拼。

> 更多参数（多路复用、音频、HTTPS 等）见 `webrtc-streamer详细说明.md`。

## 五、服务② 云台控制（onvif-ptz）

统一请求体约定：`xaddr`（ONVIF 地址）+ `userName` + `password`

| 接口 | 说明 |
|---|---|
| `POST /ptz-control` | 方向控制，参数 `x` / `y` / `zoom`（-1.0 ~ 1.0） |
| `POST /ptz-stop` | 停止云台运动 |
| `POST /getRtsp` | 获取摄像头 RTSP 地址 |
| `POST /ptz-presets` | 获取预置位列表 |
| `POST /ptz-goto-preset` | 调用预置位 |
| `GET /health` | 健康检查 |

```bash
curl -X POST http://localhost:3000/ptz-control -H "Content-Type: application/json" ^
  -d "{\"xaddr\":\"http://192.168.110.11:9080/onvif/device_service\",\"userName\":\"admin\",\"password\":\"xxx\",\"x\":0.5,\"y\":0,\"zoom\":0}"
```

## 六、服务③ 录像下载（record-service）

> 完整的参数表、响应字段表、错误码、任务状态机、Vue 封装示例，见 **`接口文档.md`**。

### 6.1 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 服务信息页（浏览器直接打开） |
| GET | `/health` | 健康检查，含 ffmpeg 可用性 |
| POST | `/search` | 查某时间段有没有录像 |
| POST | `/download` | 发起下载，立即返回 `taskId` |
| GET | `/progress?taskId=` | 查询任务进度 |
| GET | `/file?name=` | 下载成品 mp4 |
| GET | `/tasks` | 任务列表 |

### 6.2 请求参数

| 参数 | 必填 | 说明 |
|---|:---:|---|
| `cameraIp` | ✅ | 设备 IP（也可传 `xaddr`，会自动提取 IP） |
| `isapiPort` | | ISAPI 端口，**默认 80**。海康的 ISAPI 与 ONVIF **共用同一个 HTTP 端口**，填成和 ONVIF 端口一致即可 |
| `userName` | ✅ | 用户名（兼容 `username`） |
| `password` | ✅ | 密码（兼容 `pass`） |
| `channel` | | 通道号，从 1 开始，默认 1 |
| `stream` | | `main`（主码流，默认）/ `sub`（子码流） |
| `start` | ✅ | 开始时间，本地时间，格式 `2026-10-15 08:00:00` |
| `end` | ✅ | 结束时间，同上 |
| `tz` | | 时区，默认 `8`（北京） |

> 时间填**本地时间**即可，服务内部会自动转 UTC。填错时区是搜不到录像的头号原因。

### 6.3 完整调用示例

**第一步：确认那段时间有没有录像**

```bash
curl -X POST http://localhost:3001/search -H "Content-Type: application/json" ^
  -d "{\"cameraIp\":\"192.168.1.100\",\"isapiPort\":80,\"userName\":\"admin\",\"password\":\"xxx\",\"channel\":1,\"start\":\"2026-10-15 08:00:00\",\"end\":\"2026-10-15 09:00:00\"}"
```

返回：

```json
{
  "success": true,
  "count": 2,
  "segments": [
    { "start": "2026-10-15T00:00:00Z", "end": "2026-10-15T00:30:00Z" },
    { "start": "2026-10-15T00:30:00Z", "end": "2026-10-15T01:00:00Z" }
  ]
}
```

**第二步：发起下载**

```bash
curl -X POST http://localhost:3001/download -H "Content-Type: application/json" ^
  -d "{\"cameraIp\":\"192.168.1.100\",\"isapiPort\":80,\"userName\":\"admin\",\"password\":\"xxx\",\"channel\":1,\"start\":\"2026-10-15 08:00:00\",\"end\":\"2026-10-15 09:00:00\"}"
```

返回：

```json
{ "success": true, "taskId": "a1b2c3d4", "status": "queued" }
```

**第三步：轮询进度**

```bash
curl "http://localhost:3001/progress?taskId=a1b2c3d4"
```

```json
{
  "success": true,
  "status": "running",
  "percent": 45,
  "message": "下载第 2/4 段",
  "file": null
}
```

`status` 取值：`queued` → `running` → `done` / `failed`

**第四步：取文件**

```bash
curl -O -J "http://localhost:3001/file?name=ch1_20261015_080000_090000.mp4"
```

### 6.4 前端调用参考

```js
// 发起下载
const res = await fetch('http://localhost:3001/download', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    cameraIp: '192.168.1.100',
    isapiPort: 80,
    userName: 'admin',
    password: 'xxx',
    channel: 1,
    start: '2026-10-15 08:00:00',
    end: '2026-10-15 09:00:00',
  }),
});
const { taskId } = await res.json();

// 轮询进度
const timer = setInterval(async () => {
  const p = await (await fetch(`http://localhost:3001/progress?taskId=${taskId}`)).json();
  console.log(p.percent + '%', p.message);
  if (p.status === 'done') {
    clearInterval(timer);
    // 触发浏览器下载
    location.href = `http://localhost:3001/file?name=${encodeURIComponent(p.file)}`;
  }
  if (p.status === 'failed') {
    clearInterval(timer);
    console.error('失败:', p.error);
  }
}, 1500);
```

### 6.5 工作原理

```
① 查录像段   POST /ISAPI/ContentMgmt/search    → 拿到 playbackURI 列表
② 下载流     POST /ISAPI/ContentMgmt/download  → 海康私有 PS 流
③ 转 mp4     ffmpeg -i xxx.ps -c copy xxx.mp4
④ 多段合并   ffmpeg -f concat ... -c copy final.mp4
⑤ 返回文件   GET /file?name=xxx.mp4
```

跨多个录像段时会自动合并成一条完整视频。同时最多跑 2 个下载任务（可用 `RECORD_CONCURRENCY` 调整）。

## 七、环境变量

`install-service.bat` 会自动写入系统环境变量：

| 变量 | 值 | 说明 |
|---|---|---|
| `FFMPEG_PATH` | `<包目录>\tools\ffmpeg.exe` | ffmpeg 位置 |

服务本身还认这些（改 `install-service.bat` 里的 `AppEnvironmentExtra` 即可）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `RECORD_PORT` | 3001 | 下载服务端口 |
| `RECORD_DIR` | `record-service\downloads` | 成品输出目录 |
| `RECORD_TZ` | 8 | 默认时区 |
| `RECORD_CONCURRENCY` | 2 | 同时下载任务数 |

> **为什么 ffmpeg 要放包内**：服务由 NSSM 以 `LocalSystem` 身份启动，
> 看不到"用户级"PATH。即使你系统里装了 ffmpeg，服务也可能找不到。
> 包内自带一份最稳妥。

## 八、常见问题

**服务启动后立即停止？**

看日志：
- `webrtc-streamer\logs\stderr.log`
- `onvif-ptz\logs\stderr.log`
- `record-service\logs\stderr.log`

多半是端口被占：`netstat -ano | findstr :3001`

**浏览器访问 8000 是空白？**

`Win + R` 输入 `services.msc`，确认三个服务都是「正在运行」。

**下载时提示"该时间段没有录像"？**

依次排查：
1. 时间填的是不是**本地时间**（不是 UTC）
2. 设备有没有配录像计划、录像是否已被循环覆盖
3. `isapiPort` 填对没有——它应与设备的 HTTP / ONVIF 端口一致（出厂默认 80）
4. `channel` 对不对

**下载时提示"无法连接设备"？**

- 检查 `cameraIp` 是否可达：`ping 192.168.1.100`
- 检查 `isapiPort`，换个端口试（80 / 8000）
- 确认用户名密码有回放权限

**`/health` 里 `ffmpegAvailable` 是 false？**

`tools\ffmpeg.exe` 不存在。放一个进去，或设 `FFMPEG_PATH` 环境变量，然后重启服务。

**包太大？**

`tools\ffmpeg.exe` 占 212MB（full build）。可以换成 [essentials 版](https://www.gyan.dev/ffmpeg/builds/)
（约 90MB），功能对本项目完全够用。

**换了机器要重新解压吗？**

不用。整个文件夹复制过去，重新跑 `install-service.bat` + `firewall-rules.bat` 即可。

## 九、卸载

右键 `uninstall-service.bat` → **以管理员身份运行**

只删除服务注册和 `FFMPEG_PATH` 环境变量，**不删除任何程序文件**。
想彻底清理，直接删掉整个文件夹。
